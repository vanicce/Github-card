
# Retrospectiva

A public GitHub retrospective. Search a username and read the account age, original repositories, stars, main language, the busiest repository, what changed this year, and the recent public activity the API still returns.

## Index

- [Technologies Used](#technologies-used)
- [Installation](#installation)
- [Examples](#examples)

## Technologies Used

HTML, CSS, Tailwind, Vue, Pinia

## Installation

Steps required to install the project locally.

```bash
git clone https://github.com/vanicce/Github-card.git
```
```bash
cd Github-card
```
```bash
npm install
```
```bash
npm run dev
```
